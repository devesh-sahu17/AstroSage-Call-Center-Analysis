# AstroSage Call Center Analysis | Excel

## Project Overview
This project focuses on analyzing call center data for AstroSage using Microsoft Excel to understand call volume trends, agent performance, customer satisfaction, repeat callers, and revenue patterns.

The objective is to transform raw call center data into meaningful insights that can help improve operational efficiency and customer experience.

## Business Objectives
- Analyze daily, monthly, and hourly call volume trends.
- Evaluate agent performance and workload distribution.
- Identify repeat callers and understand customer calling patterns.
- Analyze customer satisfaction levels.
- Explore revenue patterns and trends.

## Tools & Techniques Used
- Microsoft Excel
- Data Cleaning and Preparation
- PivotTables and PivotCharts
- Slicers for interactive filtering
- Excel Functions
- Data Analysis and Visualization

## Key Insights
- Average daily call volume was approximately 246 calls.
- Repeat callers accounted for approximately 42% of callers.
- Analyzed agent performance and workload distribution.
- Evaluated customer satisfaction patterns.
- Explored revenue trends to understand business performance.


## Conclusion
The analysis provides insights into call center operations, customer behavior, agent performance, and revenue patterns. Excel's data analysis and visualization features helped convert raw data into actionable business insights.
